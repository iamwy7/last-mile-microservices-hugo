A Business Site to my other project [last-mile-delivery-microservices](https://github.com/iamwy7/last-mile-delivery-microservices).

That project is just an example that how build static documentation, sites and more using the [Hugo](https://gohugo.io/).

## Running project locally
- Clone the project
- Inside de project, run:
```zsh
docker run --rm -it   -v $(pwd):/src   -p 1313:1313   klakegg/hugo:0.83.1   server
```
